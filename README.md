# depviz — граф зависимостей пакетов Ubuntu (вариант 14)

Практическая работа №2 по дисциплине «Конфигурационное управление».

Инструмент визуализации графа зависимостей для менеджера пакетов apt.
Готовые менеджеры пакетов и библиотеки для получения зависимостей
не используются: индекс репозитория читается и разбирается вручную.

## Этап 1. Минимальный прототип с конфигурацией

| Параметр | Описание |
|---|---|
| `--package NAME` | имя анализируемого пакета |
| `--repo URL\|PATH` | URL индекса `Packages` репозитория или путь к файлу тестового репозитория |
| `--test-mode` | режим работы с тестовым репозиторием |
| `--version VER` | версия пакета |
| `--filter SUBSTR` | подстрока для фильтрации пакетов |

При запуске все параметры выводятся в формате `ключ=значение`.
Ошибки в любом параметре выводятся как `ошибка: ...`, код возврата 2.

## Сборка и запуск

Требуется Python 3.10+, сторонние пакеты не нужны.

```sh
./run.sh --package tar --repo http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz
run.bat --package tar --repo http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz
make test
```
