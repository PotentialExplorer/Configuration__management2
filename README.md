# depviz — граф зависимостей пакетов Ubuntu (вариант 14)

Практическая работа №2 по дисциплине «Конфигурационное управление».

Инструмент визуализации графа зависимостей для менеджера пакетов apt.
Готовые менеджеры пакетов и библиотеки для получения зависимостей
не используются: индекс репозитория читается и разбирается вручную.

## Этап 1. Минимальный прототип с конфигурацией

| Параметр | Описание |
|---|---|
| `--package NAME` | имя анализируемого пакета |
| `--repo URL\|PATH` | URL индекса `Packages` репозитория или путь к файлу тестового репозитория |
| `--test-mode` | режим работы с тестовым репозиторием |
| `--version VER` | версия пакета |
| `--filter SUBSTR` | подстрока для фильтрации пакетов |

При запуске все параметры выводятся в формате `ключ=значение`.
Ошибки в любом параметре выводятся как `ошибка: ...`, код возврата 2.

## Этап 2. Сбор данных

`--repo` — URL индекса пакетов Ubuntu, например
`http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz`.
Поддерживаются `Packages`, `Packages.gz` и `Packages.xz` (сжатие
определяется по сигнатуре), а также `file://` для локальных копий.

- Индекс разбирается вручную (формат RFC 822): блоки «поле: значение»,
  строки-продолжения, поля `Pre-Depends` и `Depends`.
- Берётся заданная версия (`--version`); без неё — самая новая по
  правилам сравнения версий Debian (реализовано в `debversion.py`,
  проверено против `dpkg --compare-versions` на 596 парах).
- Выводятся все прямые зависимости с ограничениями версий и
  альтернативами `a | b`.

```
$ ./run.sh --package bash --repo file://$PWD/tests/fixtures/ubuntu-noble-sample.packages
bash 5.2.21-2ubuntu4: прямых зависимостей 4
  Pre-Depends: libc6 (>= 2.38)
  Pre-Depends: libtinfo6 (>= 6)
  Depends: base-files (>= 2.1.12)
  Depends: debianutils (>= 5.6-0.1)
```

Файл `tests/fixtures/ubuntu-noble-sample.packages` — 50 реальных
записей из `/var/lib/dpkg/status` Ubuntu 24.04 (пакеты tar, bash,
coreutils, grep, gzip, apt и все их зависимости).

## Этап 3. Основные операции

`--mode graph` (по умолчанию) строит граф с учётом транзитивности,
`--mode deps` выводит только прямые зависимости.

- Граф строится рекурсивным обходом в глубину (DFS) в `graph.py`.
- Пакеты, имя которых содержит `--filter`, в граф не попадают и не
  обходятся.
- Циклы находятся по ребру в вершину, которая сейчас в стеке обхода:
  цикл выводится, а обход по этому ребру не продолжается.
- Тестовый режим `--test-mode`: `--repo` — путь к файлу, где пакеты
  названы большими латинскими буквами, по пакету на строку `A: B C`.

| Файл в `tests/fixtures/graphs/` | Случай |
|---|---|
| `chain.txt` | цепочка A → B → C → D |
| `diamond.txt` | общая зависимость (ромб) |
| `cycle.txt` | цикл A → B → C → A |
| `self_loop.txt` | пакет зависит сам от себя |
| `missing.txt` | зависимость не описана в репозитории |
| `complex.txt` | два цикла, общие зависимости; удобно для `--filter` |
| `broken.txt` | ошибка формата файла |

```
$ ./run.sh --test-mode --package A --repo tests/fixtures/graphs/cycle.txt
Граф зависимостей A: пакетов 4, связей 4
  A -> B
  B -> C
  C -> A, D
  D -> нет зависимостей
Циклы (1):
  A -> B -> C -> A
```

На реальных данных Ubuntu 24.04 у `tar` найден настоящий цикл
`libc6 -> libgcc-s1 -> libc6`.

## Сборка и запуск

Требуется Python 3.10+, сторонние пакеты не нужны.

```sh
./run.sh --package tar --repo http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz
run.bat --package tar --repo http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz
make test
```
